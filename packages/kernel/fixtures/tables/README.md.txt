The tables corpus (E100): the same records in six formats. For each of the
24 fixture cases (tests/fixtures/cases/*), its first workbook by path
(24 workbooks, 121,074 bytes), as:
  xlsx: the workbook itself, copied
  csv:  its first sheet, LibreOffice 24.2.7.2,
        `soffice --headless --convert-to "csv:Text - txt - csv (StarCalc):44,34,76,1" X.xlsx`
        (UTF-8, cells as shown, formulas evaluated by LibreOffice)
  json: the csv as an array of row objects keyed by the header row
        (numbers as numbers, empty cells left out)
  md:   a heading, the source path, and the csv as a pipe table
  docx: pandoc 3.1.3, `pandoc X.md -o X.docx`
  pdf:  LibreOffice 24.2.7.2, `soffice --headless --convert-to pdf X.docx`
Generated by render.py (run once by hand from this directory). Committed as
generated, so the corpus does not depend on tool versions. A cell LibreOffice
cannot evaluate is kept as it shows it (Err:522, a circular reference, in one
TOTAL row).
Used by examples/bench.rs: north/tables (E100).
