# Research scan, 2026-11-15 (E283)

The experiment loop's second job: read sources by theme, against the gaps the loop found that night. ## Incremental hashing of a changing state (E279)

- **LtHash** (Facebook engineering post, 2019; Folly's implementation): a homomorphic hash whose value is 1,024 lanes of 16 bits (2 KB). The hash of a set of rows is the lane-wise sum of each row's hash; an update subtracts the old row's hash and adds the new one. Collision resistance rests on a lattice problem. Used to verify replicated databases without rehashing them.
- **Elliptic Curve Multiset Hash** (Maitin-Shepard et al., arXiv 1601.06502): elements hashed to points on a binary elliptic curve and added; about 255-bit digests for 127-bit security, about 1,200 to 1,600 cycles per element. The paper's comparison: an additive hash modulo 2^n (what E279 uses, n = 256 over four 64-bit lanes) is weak for multisets, since lattice reduction finds collisions unless the modulus is enormous.
- For IKAM: E279's sum hash is right for what the loop needs (damage and replay errors), and its log entry says it does not resist forgery. LtHash gives forgery resistance with the same update rule, at the cost of a 2 KB state. Next: **E284**, an LtHash mode measured beside E279's.

## Compiling nets (E277, E278, E282)

- **Neco and SNAKES** (Pommereau and Fronc; the SNAKES "fast analysis" page): a colored net compiled to C through Cython, with markings specialized to the place types; the compile is slow and pays off only for large state spaces. No figures on the page.
- **TPDE** (arXiv 2505.22610): a back end built to compile faster than LLVM's at some cost in code quality, the same trade as Cranelift's.
- For IKAM: E282 found Cranelift compiles 60x to 1,200x faster than clang and repays itself after tens of thousands of steps. Neco's lesson, typed markings, matters only once colored nets are compiled; IKAM's table refuses colored nets today.

## Durable execution and checkpoints (E271, E281)

- **Checkpoints against event history** (SoftwareSeni, on LangGraph and Temporal): a snapshot runtime restarts the interrupted node from its top; a journal runtime memoizes smaller units, so only the unfinished unit reruns. The smallest memoized unit sets what a crash costs. Side effects need idempotency keys or their own step boundary; step names are keys, so renaming one reruns it.
- For IKAM: this is E271's finding (the output write does not narrow the window) and E281's (save every sqrt(2 C M)). The loop already keys firings by idempotency keys; `net_checkpoint` keys progress by the firing's key, so renaming a transition would lose it, as the source warns.

## Choosing the next experiment (E276)

- **Research preference models** (arXiv 2608.13940): to choose which of 15 candidate solutions an agent runs, a frozen language model ranking pairs scores 65% to 69% against 50% for random; given short pilot runs first (5 minutes to 4 hours) it scores 79% to 84%, and the agent reaches its 24-hour score in about 15 hours.
- **Capability-gated planning** (arXiv 2608.05085, read through a summary page, not the paper): choosing experiments by immediate information gain undervalues prerequisites (an instrument, an assay, an abstraction) that give no evidence at first but unlock later work.
- For IKAM: both agree with E276 (keep rates do not rank). The loop should order by dependencies first (a prerequisite's arcs) and spend a small budget on pilots: a short run of the fixed bench on one corpus before the full one. A pilot transition fits the net as a `cmd` with its own cpu slot.

## Keeping views current (E260, E262; the hot and cold work)

- **DBSP** (Budiu et al., arXiv 2203.16684): a database as a stream of changes; a query's incremental form works on the changes alone, in time proportional to them for linear operators; joins cost the product of the changes and keep state the size of the relation.
- For IKAM: the append's cost is mostly keeping views current (E260). DBSP's split says which of IKAM's views could be updated in proportion to an append (filters, projections, counts) and which cannot cheaply (joins, distinct). That work is the hot and cold plan's; noted here as a source for it, not run tonight.
